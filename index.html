Variables Globales y Locales

Bienvenido al mundo de Minecraft de las variables.

Variable global: es como el mundo de Minecraft, todos pueden verla y usarla.

Variable local: es como un cofre privado, solo existe dentro de su función.

Elige un ejercicio en el menú de la izquierda.

Ejercicio 1: Variable Global

La variable mundo se declara fuera de la función, por eso la función la puede usar.

var mundo = "Soy una variable global: el mundo de Minecraft";

function miFuncion() {
    document.write(mundo);
}

miFuncion(); // Salida: Soy una variable global

Ejercicio 2: Variable Local

La variable cofre se declara dentro de la función, por eso solo existe ahí.

function miFuncion() {
    var cofre = "Soy una variable local: un cofre privado";
    document.write(cofre);
}

miFuncion(); // Salida: Soy una variable local

Ejercicio 3: Global y Local juntas

La variable diamantes es global (el inventario del mundo) y la variable encontrados es local (solo existe dentro de la mina).

var diamantes = 10; // global

function minar() {
    var encontrados = 3; // local
    diamantes = diamantes + encontrados; // usa las dos
    document.write("Encontré " + encontrados + " diamantes.<br>");
    document.write("Dentro de la función tengo " + diamantes);
}

minar();
document.write(diamantes);   // Funciona: es global
document.write(encontrados); // Error: es local
